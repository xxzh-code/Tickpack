# Tickpack — 这个项目最有趣的那一刻

> 写于 2026-10-26，第一次动手前。这是我的承诺，不是需求文档。

**那一刻：你写下 6 行循环，按下 Run，然后看见「循环变成了时间」。**

左边是一段程序，右边是生成的 mcfunction。中间的方块世界里，笔尖一格一格地走，
每走一步，`over 8 as i` 里的 `i` 就加一，屏幕上对应的一行 mcfunction 亮起来。
循环不是「一口气跑完」，而是**每个 tick 迭代一次**——一行 `over` 在数据包里
真的就是一个记分板计数器加一个程序计数器，你能在计分板面板里亲眼看到
`i: 0 → 1 → 2 …`。C 程序员的直觉说「循环是瞬时的」，Tickpack 说「循环就是时钟」。

第二个「哦——」：底部那条时间轴。程序跑完后往回拖，世界倒带，方块一个一个消失，
生成出来的代码行也跟着往回走。**时间成为可以触摸的一等公民。**

所以这个项目要做的，是让「tick」这个东西看得见、摸得着、能玩：

- 程序里所有跨越时间的控制流（`over`、`wait`）都编译成显式的状态机 + 记分板，
  不是解释器魔法；
- 模拟器里的世界由**编译出来的 mcfunction** 驱动，不是另一套并行的解释器；
- 浏览器里三样东西同屏、同步：源码 / 生成的数据包 / 正在跑的世界；
- 最爽的用法：改几行代码，让乌龟画一个只属于你的图案，然后下载成一个真的
  能丢进 Minecraft 存档的数据包。

**如果哪天做的东西不再通向这一刻（比如在补一门语言的所有边角、在做一个通用
可视化编辑器），就停下来，回来看这段话。**

| 2026-10-26 | 语言的核心语义是「控制流跨 tick、状态=记分板」，`over` 每次迭代消耗 1 tick | 把 tick 当成普通语言里的一个库函数 / 宏 | 「循环变成时钟」是最直接的「哦——」，也是和 mcfunction 模型真正同构的地方 |

| 2026-10-26 | 世界 = 33×33 平面 + 一只笔（armor stand, tag=pen），内置 turtle 风格标准库 | 一开始就做通用方块世界 / 红石 / 实体物理 | 立刻能画东西、能分享图案，且生成的命令是真的 Minecraft 语法 |
